# Phase 2 Plan 01: ResizeObserver Decoupled Canvas Sizing

## Objective
- **What:** Decouple `canvas.width` and `canvas.height` assignments from `requestAnimationFrame` render loops across `OrbitalCanvas`, `KnowledgeGraphCanvas`, and `SolarFallback2D`, replacing them with an efficient `ResizeObserver` listener.
- **Why:** Satisfies PERF-01. Mutating `.width` and `.height` at 60 FPS resets the 2D canvas context, triggers browser layout thrashing, and wastes substantial CPU cycles.
- **Output:** Smooth, non-thrashing 60 FPS rendering across all 2D simulation canvases.
