# Phase 2 Plan 02: Telemetry Throttling, Trajectory Memoization & Ring Buffer

## Objective
- **What:** Throttle telemetry dispatch `onMetricsUpdate` in `OrbitalCanvas.tsx` to 10 Hz (every 100ms), memoize the 450-step `predictOrbitPath` calculation so it runs only when initial conditions change, and maintain orbital trails via ring buffer or efficient slicing instead of per-frame `.shift()`.
- **Why:** Satisfies PERF-02, PERF-03, and PERF-04. Relieves the React reconciliation engine from updating state at 60 Hz, eliminates 450 mathematical operations per frame, and reduces GC pressure.
- **Output:** Silky smooth Orbital Lab physics simulation with responsive UI controls.
